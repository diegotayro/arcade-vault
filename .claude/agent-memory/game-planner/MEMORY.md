## Preferencias

- Criterios principales del usuario: diversidad de categorías, factibilidad en Canvas 2D y reconocimiento clásico.
- `references/started-games/` está vacío al 2026-10-21: las nuevas sugerencias parten de cero.
- El usuario pide nuevas rondas sin decidir las pendientes: no repetir pendientes, mencionarlas y proponer candidatos nuevos.
- 2026-10-21: el usuario lanzó 4 instancias en paralelo (20 sugerencias) y unificó categorías a mano; usar esas categorías como canónicas (LOGIC, MEMORY, CARDS, BOARD, DEFENSE, STRATEGY, SKILL, etc.). Puntajes con «~» son aproximados.
